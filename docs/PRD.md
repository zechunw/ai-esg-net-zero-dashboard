# ESG 评估系统 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位

ESG净零契合度评估系统是一个基于AI的智能ESG诊断平台，结合路博迈（Neuberger Berman）的「净零契合度」方法论，为投资机构和企业提供动态、可视化的ESG评估服务。

### 1.2 核心价值

- **解决痛点**: 传统ESG评级工具（如SBTi、MSCI）存在数据滞后、缺乏定性判断的问题
- **差异化优势**: 动态评估 + AI定性分析 + 漂绿检测 + 可视化看板

## 2. 功能需求

### 2.1 模块一：数据输入与智能采集

**功能描述**: 系统的"燃料"，负责解决传统评级过度依赖企业过时披露的痛点。

#### 2.1.1 多元化输入界面
- 用户只需输入企业名称、股票代码
- 支持行业选择下拉菜单
- 支持手动输入ESG数据（可选模式）

#### 2.1.2 动态数据爬虫
自动从多个来源抓取实时数据：
- 官方公告（捕捉策略变更或资本支出的增减）
- 第三方ESG评级数据（MSCI, Sustainalytics, CDP）
- 新闻与舆情监测（实时捕捉漂绿/蓝洗争议性新闻）

### 2.2 模块二：精细化评估引擎

**功能描述**: 系统的"大脑"，将采用路博迈的六大子指标框架。

#### 2.2.1 六大核心维度量化
系统将企业表现拆解为1-5分的量化指标：

| 维度 | 权重 | 指标 |
|------|------|------|
| 长期抱负 | 1.2 | 净零承诺年份、与1.5°C路径一致性、SBTi认证 |
| 中短期目标 | 1.1 | 2030年减排目标、范畴1/2/3覆盖 |
| 排放绩效 | 1.3 | 年度减排率、各范畴排放趋势 |
| 信息披露 | 1.0 | TCFD/GRI/IFRS S1/S2合规、数据更新频率 |
| 脱碳策略 | 1.2 | 技术路线图、可再生能源比例 |
| 资本配置 | 1.1 | 绿色资本支出占比、绿色收入占比 |

#### 2.2.2 AI动态定性调整（高影响力调整机制）
当AI发现企业"言行不一"时，自动触发扣分：
- 承诺净零但减少绿色资本支出
- 宣称环保但存在漂绿争议

### 2.3 模块三：可视化诊断看板

**功能描述**: 将复杂数据转化为直观界面。

#### 2.3.1 契合度状态标签
以颜色标识显示企业状态：
- 🔴 不契合 (0-1.5)
- 🟠 承诺契合 (1.5-2.5)
- 🟡 部分契合 (2.5-3.5)
- 🟢 契合净零路径 (3.5-4.5)
- 🔵 正在达成净零 (4.5-5.0)

#### 2.3.2 六维雷达图
直观展示企业在六大核心维度上的得分

#### 2.3.3 优劣势深度解析
- 长处：列出得分高的原因及数据来源
- 短板：点出失分原因

### 2.4 模块四：前瞻性预警与改进建议

**功能描述**: 提供"解决方案"，赋能主动投资管理。

#### 2.4.1 改进路径指南
针对短板提出具体改进建议

#### 2.4.2 转型偏离预警
基于绿色资本支出和营收趋势，预测未来3-5年偏离1.5°C温控目标的可能性

### 2.5 模块五：高复用性与投资组合管理

**功能描述**: 支持持续的投资追踪与批次处理。

#### 2.5.1 历史追踪与对比
- 储存企业评分记录
- 生成按年/季度的变化趋势图

#### 2.5.2 同行基准对比
- 自动调出同行业平均基准
- 判断竞争优势

#### 2.5.3 报告一键生成
- 支持导出PDF报告
- 支持导出Excel数据

## 3. 技术需求

### 3.1 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端框架 | HTML5 + CSS3 + JavaScript |
| 图表库 | ECharts 5.x |
| 后端框架 | Python Flask |
| AI模型 | OpenAI GPT-4 / Claude |
| 数据爬虫 | BeautifulSoup4 |
| 报告生成 | ReportLab (PDF), openpyxl (Excel) |
